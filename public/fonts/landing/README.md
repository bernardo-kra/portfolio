# Fontes da landing (`/landing`)

Servidas localmente apenas quando a rota `/landing` é carregada. Subconjunto latino em WOFF2, obtido da API oficial do Google Fonts.

- `geist.woff2` (variável, 300–700) e `geist-mono.woff2`: Geist e Geist Mono, de The Geist Project Authors / Vercel. SIL Open Font License 1.1 em `geist-OFL.txt` e `geist-mono-OFL.txt`.
- `instrument-serif.woff2` e `instrument-serif-italic.woff2`: Instrument Serif, de The Instrument Serif Project Authors. SIL Open Font License 1.1 em `instrument-serif-OFL.txt`.
